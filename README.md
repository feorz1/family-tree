# Семейная родословная

Рабочая семейная версия по рассказам и предоставленным материалам. Связи нуждаются в подтверждении по документам; архивные совпадения отдельно отмечены как зацепки.

- `index.html` — визуальное древо, открывается в браузере. Переключатель «Простые / Сложные» меняет линии во всех ветвях; по умолчанию включены простые. Нажмите карточку или линию, чтобы выделить связанных людей; по кнопке «Подробнее» открываются сведения и источники. Перетаскивайте фон, используйте Ctrl/⌘ и колёсико или кнопки внутри схемы для масштаба. Шкала слева показывает известные годы рождения. Красным показаны неустановленные связи и возможные совпадения, синим — усыновление и восприемники; остальные семейные связи основаны на рассказах и требуют проверки.
- `semeinoe-drevo.ged` — переносимый файл GEDCOM 5.5.1; совместимость с конкретной генеалогической программой ещё не проверена.
- `research.md` — исследовательские заметки и вопросы для дальнейших проверок.
- `tests/tree.test.cjs` — проверка связей и управления схемой; запуск: `node tests/tree.test.cjs`.

Документы, оригиналы снимков и результаты ДНК не включены. История содержит персональные и семейные сведения: репозиторий предназначен для закрытого доступа.
